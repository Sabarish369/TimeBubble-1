# **App Name**: TimeBubble

## Core Features:

- Daily Canvas System: A visual time-blocking system using draggable bubbles on a 24-hour timeline.
- Bubble Creation & Management: Tools to create, edit, and manage time bubbles (rounded rectangles) with drag and drop functionality for resizing and repositioning. User actions: rename, duplicate, delete, and change color. Uses context menu for some.
- Time Management: 24-hour timeline display with a current time indicator and visual distinction between past, present, and future. Snap to grid to avoid overlaps. Prevents overlapping bubbles.
- Reflection System: A system for user to provide timestamped mood and productivity scores and a notes field for each bubble. Includes input components and data models.
- Data Persistence: Automatic saving of time bubble data every 30 seconds to browser localStorage.  Includes data import and export functionality.
- Smart Suggestions: Use of AI tool that provides the user with suggestions based on their usage patterns to encourage optimal planning.

## Style Guidelines:

- Primary color: Soft lavender (#D1C4E9) to promote calmness and focus.
- Background color: Light grey (#F5F5F5), nearly white, to provide a clean, unobtrusive backdrop.
- Accent color: Pale peach (#FFDAB9) for interactive elements and highlights.
- Body and headline font: 'Inter' (sans-serif) for a clean, rounded, and modern look.
- Minimalist line icons for bubble categories and quick actions.
- Clean, minimalist layout with a focus on drag-and-drop functionality. Clear visual hierarchy to indicate the current time and planned activities.
- Subtle animations for bubble creation, editing, and completion to provide gentle feedback.
